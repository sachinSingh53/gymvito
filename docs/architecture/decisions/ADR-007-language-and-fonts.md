# ADR-007: Languages and fonts

Status: Accepted for engineering; native-speaker review pending

The MVP language pair is English and Hindi for an India-first launch, with INR as the Phase 0 sample currency. Bundle Noto Sans Devanagari and inline its bytes into HTML used for PDFs so rendering does not depend on the device or network. Translation parity and placeholders are CI-checked.

Month-based plans use a clamped calendar anniversary followed by one day subtraction for an inclusive end date. For example, a one-month plan starting 2024-01-31 ends 2024-02-28. This product decision must be confirmed before Phase 3.
